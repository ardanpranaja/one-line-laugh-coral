A single hilarious line of at most 200 characters — my entry for the make.fun bounty "One Line, One Laugh". The line is the whole entry: one joke, one turn, no explanation.

## The entry

> I asked AI to write my will and it left everything to the cloud — turns out even my death has a subscription now.

`main.ts` writes that line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader container), after checking it is a single non-blank line of 1–200 characters.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
